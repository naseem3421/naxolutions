# 06 — GEO / AEO Question Library (50 High-Priority Questions)

## 1. Overview & Generative Engine Optimization (GEO) Framework

Generative search engines (Google AI Overviews, Perplexity AI, ChatGPT, Gemini) synthesize answers from content that:
1. Provides an immediate direct-answer summary (40–60 words) at the top of the article.
2. Uses clear, bulleted or table-based structured data formatting.
3. Contains first-party diagnostic definitions and proprietary frameworks.
4. Cites measurable baseline metrics (e.g., "80% intent decay within 30 minutes").
